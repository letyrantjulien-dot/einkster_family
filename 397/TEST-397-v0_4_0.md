# E!nkster 397 v0.4.0: the keyboard everywhere
28 October 2026. Julien's ship of 28.10: "You can ship the 397 keyboard everywhere before the cat toy mode. Now." No desk mode: the 397 sleeps as before, on battery and on USB. After v0.3.0. `ek_shared.h`, `fonts.h` and the packs are unchanged.

**What ships:** the paired keyboard drives every screen of the 397 next to the dial, and **Esc always does what a long press does**.

## The keys
| Where | Keys |
|---|---|
| **Tiles** | ← → (or ↑ ↓) previous / next tile · **1–7** straight to a tile (1 Clock, 2 Climate, 3 Editions, 4 Typewriter, 5 Archives, 6 Catalog, 7 Device) · Enter or space opens · Esc goes to the Clock |
| **Lists** (the Editions shelf, sections and cards, the archives, the Catalog, the Device menu) | ↑ ↓ move · Page Up / Page Down a screen · Home / End · Enter or → opens · Esc, ← or Backspace goes back · **a letter or digit** jumps to the next row starting with it (in the Device menu, b goes to Battery, k to Keyboard) |
| **Editions cards** | space, → or Page Down: next page or card · ← or Page Up: back · Enter shows a question's answer, otherwise turns · Esc back to the list |
| **Catalog codes** | ← → previous / next code · Enter or Esc back |
| **About, Battery** | Enter or Esc back |
| **Set up** | Esc closes the hotspot page |
| **Typewriter** | as before, plus **Esc leaves**. A line not yet saved is kept, as with the long press. |
| **Archives** | as in v0.3.0 |

Note: inside a list, the digits jump to rows. To reach a tile by number, press Esc first.

## How the keyboard connects
- **It can't wake the 397:** in sleep the radio is off. The first touch is the dial, or PWR when it's switched off.
- **After a person's wake** (dial or power-on), the 397 listens for the paired keyboard for a minute, in one-second rounds in the background, so the dial stays free. Press a key and the keyboard is back within a second or two. The field log says "[keyboard] back, no new pairing".
- **Timer wakes** (the clock, the 30-minute samples) never listen (checked on the bench).
- **Awake time:**
  - with the keyboard connected, 2 minutes after the last key, and 10 minutes on an archive page;
  - otherwise 45 s, as before (65 s while it is still listening).
- **When it sleeps,** the keyboard is let go. Leaving the typewriter or the archives no longer drops it: it stays for the tiles.
- **Device > menu,** row 4: **"Keyboard: pair one"** when none is paired (the same list and code as in the typewriter). Once paired, the row says **"Keyboard: forget it"**, with the keyboard's battery on the right.

## Flash
`einkster397-v0_4_0-nokeys-update.bin` at **0x10000**. It keeps everything: networks, clock, logs and the pairing.

## What was checked
- **The board build:** it compiles with the GitHub build's compiler, with no warning in our files (checked).
  - Firmware: 2,120,862 bytes with no keys.
  - Globals: 160,876 bytes. The state kept through sleep: 3,880 of 8,192 bytes, unchanged.
- **The full image:** the app at 0x10000 is the update file byte for byte (checked).
- **The bench: 126 checks, 0 failed.** The new keyboard scene drives the 397 by keys alone:
  - switched on, the keyboard comes back; arrows and Enter go into Editions, down to a card; space turns the page and Esc goes back;
  - 7, Enter, b, Enter opens the battery page;
  - a dial wake brings the keyboard back, then End, Esc and 1 return to the Clock;
  - 6, Enter, Enter, → opens the Catalog's second code;
  - 4, Enter, "ok", Enter, Esc, 1: the typewriter saves the line, Esc leaves it, and the keys still drive the tiles;
  - 5, Enter, Enter, "berlin", Enter opens Berlin in the archives;
  - k in the Device menu forgets the keyboard, and the same row pairs it again;
  - three hours of timer wakes never listen;
  - every partial refresh starts from what the paper shows.
- **Not checked:**
  - on the board, the background listening and how fast the keyboard comes back;
  - the Esc on the set-up page (the bench has no hotspot);
  - the hotspot and the keyboard together.

## Test plan
1. **Flash.** Turn the dial once, then press a key: the 397 should answer within a second or two.
2. **Tiles:** try 1 to 7, ← →, Enter, Esc.
3. **Lists and cards:** in Editions, use ↑ ↓, a letter, Enter, space and Esc.
4. **The Device menu:** b for Battery, k for the keyboard row.
5. **The typewriter:** Esc out of it, then 1 for the Clock.
6. **Sleep:** leave it 2 minutes and it sleeps. Turn the dial, press a key: the keys work again.
7. **Send the field log** after a day: each "[keyboard] back" line marks a reconnection.
